action/insert.php
Prepare SQL Query
$stmt = $pdo->prepare("INSERT INTO employees(name,email,status) VALUES(?,?,?)");

 This creates a prepared statement

What does (?,?,?) mean?

These are placeholders for values.

✔ Benefits:

Prevents SQL Injection
Separates query from data
Faster for repeated queries

$_POST → gets user input
prepare() → creates secure SQL query
? → placeholders
execute() → binds values + runs query
Prevents SQL injection
